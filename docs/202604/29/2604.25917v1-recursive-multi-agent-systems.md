## 摘要
递归或循环语言模型最近作为一种新的扩展轴出现，通过在潜状态上迭代优化相同的模型计算来深化推理。我们将这种扩展原则从单一模型推广到多智能体系统，并提出疑问：智能体协作本身是否可以通过递归进行扩展？为此，我们引入了 RecursiveMAS，这是一个递归多智能体框架，将整个系统建模为统一的潜空间递归计算。RecursiveMAS 通过轻量级的 RecursiveLink 模块将异构智能体连接为协作循环，从而实现分布内潜思维生成和跨智能体潜状态传输。为了优化该框架，我们开发了一种内外循环学习算法，通过跨递归轮次的共享基于梯度的信用分配，实现迭代式的全系统协同优化。对运行时间复杂度和学习动力学的理论分析表明，RecursiveMAS 比标准的基于文本的多智能体系统更高效，并在递归训练期间保持稳定的梯度。在实验方面，我们在 4 种具有代表性的智能体协作模式下实例化了 RecursiveMAS，并在涵盖数学、科学、医学、搜索和代码生成的 9 个基准测试中进行了评估。与先进的单/多智能体和递归计算基准相比，RecursiveMAS 始终能带来 8.3% 的平均准确率提升，同时实现 1.2 倍至 2.4 倍的端到端推理加速，并减少 34.6% 至 75.6% 的 token 使用量。代码和数据已在 https://recursivemas.github.io 提供。

## Abstract
Recursive or looped language models have recently emerged as a new scaling axis by iteratively refining the same model computation over latent states to deepen reasoning. We extend such scaling principle from a single model to multi-agent systems, and ask: Can agent collaboration itself be scaled through recursion? To this end, we introduce RecursiveMAS, a recursive multi-agent framework that casts the entire system as a unified latent-space recursive computation. RecursiveMAS connects heterogeneous agents as a collaboration loop through the lightweight RecursiveLink module, enabling in-distribution latent thoughts generation and cross-agent latent state transfer. To optimize our framework, we develop an inner-outer loop learning algorithm for iterative whole-system co-optimization through shared gradient-based credit assignment across recursion rounds. Theoretical analyses of runtime complexity and learning dynamics establish that RecursiveMAS is more efficient than standard text-based MAS and maintains stable gradients during recursive training. Empirically, we instantiate RecursiveMAS under 4 representative agent collaboration patterns and evaluate across 9 benchmarks spanning mathematics, science, medicine, search, and code generation. In comparison with advanced single/multi-agent and recursive computation baselines, RecursiveMAS consistently delivers an average accuracy improvement of 8.3%, together with 1.2$\times$-2.4$\times$ end-to-end inference speedup, and 34.6%-75.6% token usage reduction. Code and Data are provided in https://recursivemas.github.io.

*   **研究动机**：虽然多智能体系统（MAS）能通过协作提升大模型的性能，但传统的基于文本的协作存在三大瓶颈：

    2.  **计算效率低下**：智能体间频繁的文本生成和解析导致高延迟和高 Token 消耗。
    3.  **优化困难**：文本交互阻断了梯度流，难以对整个系统进行端到端的协同优化。
*   **核心问题**：能否借鉴单模型递归计算（Recursive LM）的思路，将多智能体协作转化为统一的潜空间（Latent Space）递归过程，从而实现性能与效率的双重扩展？

### 2. 方法论
RecursiveMAS 框架将整个多智能体系统视为一个统一的潜空间递归计算图。
*   **核心思想**：放弃文本中介，让智能体通过“潜思维”（Latent Thoughts）直接在隐藏层表示空间进行循环协作。
*   **关键技术细节**：
    *   **RecursiveLink 模块**：一个轻量级的两层残差投影模块。
        *   **Inner Link（内环链接）**：在单个智能体内部，将最后一层的隐藏状态映射回输入嵌入空间，实现自回归的潜思维生成。
        *   **Outer Link（外环链接）**：在异构智能体之间，解决不同模型维度和分布不一致的问题，实现跨模型的潜状态传输。
    *   **内外环学习算法（Inner-Outer Loop Learning）**：
        *   **内环训练**：对每个智能体进行预热，使其 Inner Link 能够对齐潜思维与语义分布。
        *   **外环训练**：在系统层面进行递归展开，通过最终输出的交叉熵损失，利用反向传播对所有 Outer Link 进行协同优化。
*   **理论支撑**：论文证明了潜空间递归相比文本递归具有更低的运行复杂度（$\Theta(md_h^2)$ vs $\Theta(m|V|d_h)$），且能保持梯度稳定性，避免文本离散化导致的梯度消失。

### 6. 主要结论与发现
*   **性能提升**：RecursiveMAS 在所有基准上平均准确率提升 **8.3%**，且随递归深度增加，领先优势扩大。
*   **效率飞跃**：相比文本递归系统，实现了 **1.2x - 2.4x 的推理加速**，并减少了 **34.6% - 75.6% 的 Token 消耗**。
*   **扩展律**：发现训练递归轮次和推理递归轮次具有协同效应，增加推理深度能进一步释放训练阶段习得的递归能力。
*   **结构无关性**：该方法能无缝适配各种 MAS 拓扑结构（如混合专家或工具调用），具有极强的通用性。

### 7. 优点
*   **高效性**：通过潜空间交互规避了昂贵的文本解码/编码过程，解决了 MAS 的延迟痛点。
*   **可优化性**：首次实现了多智能体系统级别的端到端梯度优化，理论证明了其梯度流的稳定性。
*   **轻量化**：仅需训练极少量的投影参数即可带动异构大模型集群的协同进化。

### 8. 不足与局限
*   **可解释性挑战**：潜空间中的“思维”对人类不可见，相比文本协作，调试和追踪智能体中间推理过程的难度增加。
*   **训练依赖**：虽然轻量，但仍需针对特定任务进行内外环微调，无法像纯 Prompt 方案那样实现完全的零样本迁移。
*   **递归深度上限**：实验最高仅展示到 3 轮递归，更深层次的递归是否会出现语义漂移或过拟合尚待研究。
