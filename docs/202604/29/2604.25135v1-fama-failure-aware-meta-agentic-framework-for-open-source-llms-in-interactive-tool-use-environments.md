## 摘要
大语言模型（LLMs）正越来越多地被部署为能够改变外部环境的自主智能体的决策核心。然而，在模拟真实世界以客户为中心的问题解决场景的对话基准测试中，由于错误决策的级联效应，这些智能体经常失败。对于参数规模较小、上下文窗口有限且推理预算受限的开源 LLM 而言，这些挑战尤为突出，这导致了智能体设置中错误积累的增加。为了应对这些挑战，我们提出了故障感知元智能体（FAMA）框架。FAMA 分两个阶段运行：首先，它分析基线智能体的失败轨迹，以识别最普遍的错误；其次，它采用一种编排机制，激活专门针对这些失败而定制的最小化专业智能体子集，在决策步骤之前为工具使用智能体注入针对性的上下文。在开源 LLM 上的实验表明，在各种评估模式下，其性能比标准基线提高了多达 27%。这些结果强调，通过专业智能体针对性地策划上下文以解决常见故障，是构建可靠的、模拟真实对话场景的多轮工具使用 LLM 智能体的一项有价值的设计原则。

## Abstract
Large Language Models are being increasingly deployed as the decision-making core of autonomous agents capable of effecting change in external environments. Yet, in conversational benchmarks, which simulate real-world customer-centric issue resolution scenarios, these agents frequently fail due to the cascading effects of incorrect decision-making. These challenges are particularly pronounced for open-source LLMs with smaller parameter sizes, limited context windows, and constrained inference budgets, which contribute to increased error accumulation in agentic settings. To tackle these challenges, we present the Failure-Aware Meta-Agentic (FAMA) framework. FAMA operates in two stages: first, it analyzes failure trajectories from baseline agents to identify the most prevalent errors; second, it employs an orchestration mechanism that activates a minimal subset of specialized agents tailored to address these failures by injecting a targeted context for the tool-use agent before the decision-making step. Experiments across open-source LLMs demonstrate performance gains up to 27% across evaluation modes over standard baselines. These results highlight that targeted curation of context through specialized agents to address common failures is a valuable design principle for building reliable, multi-turn tool-use LLM agents that simulate real-world conversational scenarios.

### 论文总结：FAMA 框架

#### 1. 核心问题与整体含义（研究动机和背景）
在多轮交互式工具使用（Tool Use）场景中，开源大语言模型（LLMs）常因参数规模较小、上下文窗口有限以及推理预算受限，容易在决策过程中产生错误。这些初始错误会产生“级联效应”，导致后续步骤不断偏离目标，最终任务失败。现有的改进方法（如微调或强化学习）成本高昂且难以针对特定失败模式进行优化，而静态的多智能体框架往往会注入过多无关上下文，导致小模型处理过载。
**FAMA（Failure-Aware Meta-Agentic）** 框架的研究动机在于：通过动态识别模型的特定失败模式，仅激活必要的专业化子智能体来修复上下文，从而在资源受限的情况下提升开源模型的可靠性。

#### 2. 方法论：核心思想与关键技术
FAMA 采用一种“元智能体”设计，不直接参与环境交互，而是通过观察和诊断来优化主智能体的决策环境。其核心流程分为两个阶段：

*   **阶段 1：故障诊断（Failure Analysis）**
    *   分析基线智能体在任务中的失败轨迹。
    *   定义了四类核心错误：**领域策略违规（DCV）**、**复杂工具输出检索错误（WRCO）**、**上下文误解与幻觉（CM）**、**完成不全或过早停止（IFU）**。
    *   利用独立的错误分析智能体对失败案例进行分类并给出理由。
*   **阶段 2：动态编排与缓解（Orchestration & Mitigation）**
    *   **编排智能体（Orchestrator）：** 综合各分析智能体的输出，确定导致失败的主要根源。
    *   **缓解智能体（Mitigation）：** 根据识别出的错误类型，从预定义的智能体池（如领域约束提取器 DCE、工具建议智能体 TSA、内存模块 Memory 等）中挑选出**最小子集**。
    *   **执行：** 在决策前，仅将选定子智能体生成的针对性信息注入主智能体的上下文，引导其做出正确决策。

#### 6. 主要结论与发现
*   **性能显著提升：** FAMA 在各基准测试中均优于基线，在 $\tau$-bench 上提升约 25%，在 ACEBench 上提升达 27%。
*   **“少即是多”：** 盲目使用所有辅助智能体（如 IRMA）有时会因上下文过载反而降低性能；FAMA 通过动态选择最小智能体子集，在保持高性能的同时减少了约 20%-30% 的 Token 开销。
*   **错误模式具有模型特异性：** 不同规模的模型在不同领域表现出的主导错误不同，证明了动态编排的必要性。
*   **内存是瓶颈：** 实验发现 Memory 模块和领域约束提取器（DCE）是提升开源模型表现最常被推荐的组件。

#### 7. 优点
*   **动态性与灵活性：** 能够根据模型表现自动调整策略，而非使用一成不变的 Prompt。
*   **资源效率：** 针对开源小模型优化，避免了长上下文导致的性能下降和成本激增。
*   **通用性：** 框架设计不依赖于特定模型架构，可扩展至新的错误类型和辅助智能体。

#### 8. 不足与局限
*   **依赖预定义池：** FAMA 的效果受限于预设的辅助智能体质量和覆盖范围，无法自动生成全新的修复策略。
*   **推理延迟：** 虽然比全量多智能体框架快，但相比单模型 ReAct，仍增加了额外的推理步骤和延迟。
*   **场景局限：** 目前主要集中在结构化的对话和工具使用任务，在更开放、无固定 API 的任务中表现尚待验证。
*   **判断模型依赖：** 框架在诊断阶段依赖于更强大的模型（如 GPT-4o），在完全脱离闭源模型的纯开源生态中可能面临挑战。
