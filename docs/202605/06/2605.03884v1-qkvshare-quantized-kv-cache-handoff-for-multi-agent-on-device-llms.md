## 摘要
边缘设备上的多智能体大语言模型（LLM）系统需要高效地移交潜在上下文，但目前的实际选择通常是昂贵的重新预填充（re-prefill）或全精度 KV 传输。我们研究了 QKVShare，这是一个用于智能体之间量化 KV 缓存移交的框架，它结合了 Token 级混合精度分配、自包含的 CacheCard 表示以及与 HuggingFace 兼容的缓存注入路径。我们目前的结果支持一个比初稿更具体但更清晰的结论：在 Llama-3.1-8B-Instruct 处理 150 个 GSM8K 问题时，自适应量化在重复移交下保持了竞争力，并且在更深跳数、更高预算的设置中，相比均匀量化表现出最明显的优势；在移交延迟方面，QKVShare 路径在所有测试的上下文中都降低了相对于完全重新预填充的首字生成时间（TTFT），从标称 1K 上下文下的 130.7 ms（对比 150.2 ms）到标称 8K 上下文下的 397.1 ms（对比 1029.7 ms）。阶段计时显示，注入后的生成过程而非 Card 创建在当前的 QKVShare 延迟路径中占据主导地位。这些结果将量化 KV 移交定位为一个极具前景的端侧系统研究方向，同时也强调了对更强的控制器消融实验和公平运行时比较的需求。

## Abstract
Multi-agent LLM systems on edge devices need to hand off latent context efficiently, but the practical choices today are expensive re-prefill or full-precision KV transfer. We study QKVShare, a framework for quantized KV-cache handoff between agents that combines token-level mixed-precision allocation, a self-contained CacheCard representation, and a HuggingFace-compatible cache injection path. Our current results support a narrower but clearer story than the original draft: on 150 GSM8K problems with Llama-3.1-8B-Instruct, adaptive quantization remains competitive under repeated handoff and shows its clearest gains against uniform quantization in deeper-hop, higher budget settings; for handoff latency, the QKVShare path reduces TTFT relative to full re prefill at every tested context, from 130.7 ms vs. 150.2 ms at nominal 1K context to 397.1 ms vs. 1029.7 ms at nominal 8K context;. Stage timing shows that post-injection generation, not card creation, dominates the current QKVShare latency path. These results position quantized KV handoff as a promising on-device systems direction while also highlighting the need for stronger controller ablations and apples-to-apples runtime comparisons.

### 1. 核心问题与整体含义（研究动机和背景）
在边缘设备（如手机、笔记本电脑）上运行多智能体大语言模型（LLM）系统时，智能体之间需要频繁移交上下文。目前的处理方式存在两难困境：
*   **重新预填充（Re-prefill）：** 接收方从头计算 KV 缓存，浪费计算资源和时间（高延迟）。
*   **全精度传输（FP16/BF16）：** 直接传输原始 KV 缓存，消耗巨大的内存和带宽。
**QKVShare** 的研究动机在于探索一种**量化 KV 缓存移交**机制，通过在智能体间传递压缩后的潜在状态，平衡内存占用与推理延迟，解决端侧多智能体协作的系统瓶颈。

### 2. 方法论：核心思想与关键技术
QKVShare 提出了一个完整的量化移交框架，核心包含三个部分：
*   **智能体拓扑感知的 Token 评分：** 扩展了现有的自适应量化方法（如“Don’t Waste Bits”），不仅考虑 Token 对当前智能体的重要性 $I(t)$，还引入了**下游需求信号 $D(t)$**。
    *   **公式：** 综合评分 $S(t) = \alpha \cdot I(t) + (1 - \alpha) \cdot T(t)$。其中 $T(t)$ 基于段级先验（如系统提示词）和注意力锚点重叠度来估算 Token 对后续智能体的价值。
*   **自适应位宽分配：** 使用一个轻量级 MLP 控制器（512 参数），根据 Token 的频率、质量得分、注意力方差、熵、下游需求和段类型，动态分配位宽（2, 4, 8 或 16 bit）。
*   **CacheCard 协议与注入：** 定义了一种紧凑的工件格式 `CacheCard`，封装了量化后的 KV 组及其元数据。接收方通过一个兼容 HuggingFace 的路径将 `CacheCard` 反量化并注入到自身的 `past_key_values` 中。

### 6. 主要结论与发现
*   **延迟大幅降低：** 在 8K 上下文下，QKVShare 将 TTFT（首字生成时间）从重新预填充的 **1029.7 ms 降低至 397.1 ms**。

*   **内存增益：** 均匀 Q4 量化相比 FP16 能在相同内存下支持多 2.8 倍的并发智能体上下文。

*   **端侧聚焦：** 针对显存受限的移动端 GPU 进行了专门的密度分析和延迟分解。
