## 摘要
大语言模型（LLMs）的最新进展使得在基于微服务的系统（MSS）中自动化根因分析（RCA）的早期尝试成为可能。然而，先前的工作通常依赖于沿单一诊断路径进行的线性推理过程。在本文中，我们提出了 LATS-RCA，这是一个基于 LLM 的用于 MSS 中 RCA 的多智能体框架。LATS-RCA 使用语言智能体树搜索（Language Agent Tree Search）算法，将 RCA 建模为由反思引导的树状结构搜索。在 LATS-RCA 中，多个由 LLM 驱动的智能体通过对执行日志和性能指标进行推理，迭代地为每个微服务执行 RCA，以收集用于根因探索的运行证据。源自中间诊断状态的反思分数被用于引导搜索，根据积累的证据指向最可能的根因。我们在开源工业级 MSS Light-OAuth2 (LO2) 上使用公开数据集评估了 LATS-RCA，并在一家运营复杂度显著更高的案例公司的生产微服务环境 (Prod) 中进行了评估。LO2 是一个采用同构技术栈的小型团队 Java 系统。在 LO2 上的结果表明，LATS-RCA 实现了较高的诊断准确率，我们还进一步基准测试了其相关的计算成本。与 LO2 相比，Prod 环境下的诊断准确率较低，且计算成本更高。Prod 部署证明了 LATS-RCA 在真实世界 MSS 中的实际适用性，并反映了生产规模 MSS 所带来的多语言技术栈、源组件不同的日志记录实践以及多因素根因等挑战。

## Abstract
Recent advances in large language models (LLMs) have enabled early attempts to automate root cause analysis (RCA) in microservice-based systems (MSS). Yet, prior works typically rely on a linear reasoning process that proceeds along a single diagnostic path. In this paper, we propose LATS-RCA, an LLM-based multi-agent framework for RCA in MSS. LATS-RCA formulates RCA as a reflection-guided tree-structured search using a Language Agent Tree Search algorithm. In LATS-RCA, multiple LLM-driven agents iteratively perform RCA for each microservice by reasoning over its execution logs and performance metrics to collect operational evidence for root cause exploration. Reflection scores derived from intermediate diagnostic states are used to guide the search toward the most likely root cause based on accumulated evidence. We evaluate LATS-RCA on the open-source industrial MSS, Light-OAuth2 (LO2), using a publicly available dataset and in a production microservice environment (Prod) in a case company with substantially higher operational complexity. LO2 is a small-team Java system with a homogeneous technology stack. The results on LO2 show that LATS-RCA achieves high diagnostic accuracy, and we further benchmark its associated computational costs. Compared to LO2, Prod attains lower diagnostic accuracy and incurs higher computational cost. The Prod deployment demonstrates the practical applicability of LATS-RCA in real-world MSS and reflects the challenges introduced by polyglot tech stack, varied logging practices of source components, and multi-factor root-causes by production-scale MSS.

### 论文总结：微服务中根因分析的多智能体系统 (LATS-RCA)

#### 1. 论文的核心问题与整体含义
随着微服务架构（MSS）的普及，系统运维中的根因分析（RCA）变得愈发复杂。现有的基于大语言模型（LLM）的自动化 RCA 方法（如 RCAgent、MicroRCA）大多采用**线性推理路径**，即单一的分析步骤序列。然而，在实际生产中，异常现象往往指向多个潜在组件，线性推理难以处理这种歧义性。本文提出了 **LATS-RCA** 框架，旨在通过**多智能体协同**和**树状搜索算法**，将 RCA 过程从单一路径扩展为多路径的探索与反思过程，从而提高诊断的准确性和鲁棒性。

#### 2. 论文提出的方法论
LATS-RCA 的核心思想是将根因分析建模为一个由反思引导的树状搜索问题，采用 **语言智能体树搜索 (Language Agent Tree Search, LATS)** 算法。

*   **多智能体架构**：
    *   **日志智能体 (Log Agent)**：负责查询和分析执行日志。
    *   **指标智能体 (Metric Agent)**：负责分析性能指标（如 CPU、内存）并生成可视化对比。
    *   **主管智能体 (Supervisor)**：负责跨模态的协调、任务移交（Handoff）以及最终的证据关联评估。
*   **关键技术细节（LATS 流程）**：
    1.  **选择 (Selection)**：使用 **UCT (置信区间上界)** 公式平衡探索（尝试新路径）与利用（深入已知高分路径）。
    2.  **扩展 (Expansion)**：在当前节点采样多个候选动作（如不同的查询指令）。
    3.  **反思与奖励计算 (Reflection & Reward)**：LLM 对动作进行评分，维度包括证据质量、诊断完整性和内部一致性。最终奖励结合了反思分数和自一致性项。
    4.  **回传 (Backpropagation)**：将奖励值沿搜索路径回传，更新节点价值估计。
*   **跨模态协作**：当某一智能体进展不足时，主管智能体会将当前证据摘要传递给另一模态的智能体进行交叉验证。

#### 6. 论文的主要结论与发现
*   **准确率显著提升**：在 LO2 数据集上，LATS-RCA 达到了 **91.3%** 的准确率，远高于单智能体 ReAct (39.8%) 和多智能体 ReAct (57.4%)。
*   **搜索胜过数据收集**：性能提升主要源于对假设空间的系统性探索（搜索广度提升 3.7 倍），而非收集了更多的原始数据。
*   **生产环境挑战**：在真实 Prod 环境中，准确率下降至 **60-70%**。这反映了多语言技术栈、非标准日志格式以及多因素诱发故障对自动化 RCA 构成的巨大挑战。

#### 7. 优点
*   **非线性推理**：引入树搜索机制，有效解决了 RCA 中证据模糊导致的误判问题。
*   **多智能体协同**：通过日志和指标智能体的分工，实现了跨模态的证据链闭环。
*   **实战验证**：不仅在受控数据集上表现优异，还直接部署于拥有 30 万网站规模的真实生产环境，具有极强的工程参考价值。

#### 8. 不足与局限
*   **计算成本高昂**：相比线性推理，LATS-RCA 的 token 消耗和响应延迟显著增加，可能限制其在极高实时性要求的场景下的应用。
*   **生产环境敏感性**：对日志的结构化程度有一定依赖，面对完全无结构的旧系统日志可能需要额外的预处理。
*   **评估局限**：目前采用二元（对/错）评估，但在复杂生产中，根因往往是多维度的，单一标签可能无法完全体现诊断的价值。
