## 摘要
记忆系统被广泛用于增强大语言模型（LLMs）处理长程任务的能力，通常被组织为包含记忆构建、摘要和检索智能体的多智能体流水线。为了增强该系统，现有的基于强化学习（RL）的方法要么对所有智能体统一应用最终的下游任务奖励（例如问答准确率），这种方式较为粗糙且模糊；要么为不同子任务上的智能体设计特定任务的奖励，这需要昂贵的标注（例如关键证据）且难以可靠地定义。为了解决这些局限性，我们提出了面向多智能体记忆系统的基于树的信用分配（TreeMem），它在无需特定任务标注的情况下，从最终奖励中推导出特定于智能体的信用。具体而言，TreeMem 将多智能体流水线（构建者-摘要者-检索者）扩展为树状结构，其中每个智能体的输出都被扩展为多个后续分支。每个智能体的贡献通过对其后续分支进行蒙特卡洛平均来估计，从而捕捉中间智能体动作如何影响最终奖励。这将粗糙的最终奖励转化为特定于智能体的优化信号。随后，这些信号被用于同时更新所有智能体的策略，帮助异构智能体有效地实现专业化。在长程基准测试上的实验表明，TreeMem 相比强基准模型提升了记忆系统的性能，验证了树状结构信用分配在多智能体记忆系统中的有效性。

## Abstract
Memory systems are widely adopted to enhance LLMs for long-horizon tasks, and are commonly organized as multi-agent pipelines with memory building, summarizing, and retrieval agents. To empower this system, existing RL-based methods either apply final downstream task rewards (e.g., QA accuracy) for all agents uniformly, which are coarse and ambiguous, or design task-specific rewards for agents on different subtasks, which require costly annotations (e.g., key evidence) and are difficult to define reliably. To address these limitations, we propose Tree-based Credit Assignment for Multi-Agent Memory Systems (TreeMem), which derives agent-specific credit from the final reward without task-specific annotations. Specifically, TreeMem extends the multi-agent pipeline (builder--summarizer--retrieval) into a tree structure, where each agent's outputs are expanded into multiple subsequent branches. The contribution of each agent is estimated via Monte Carlo averaging over its subsequent branches, capturing how intermediate agent actions may influence the final reward. This converts the coarse final reward into agent-specific optimization signals. These signals are then used to update all agent policies simultaneously, helping heterogeneous agents specialize effectively. Experiments on long-horizon benchmarks show that TreeMem improves memory system performance over strong baselines, validating the effectiveness of tree-structured credit assignment for the multi-agent memory system.

*   **研究动机**：现有的强化学习（RL）优化方法存在两难困境：一是使用统一的最终奖励（如 QA 准确率），这会导致信号过于粗糙且模糊，难以指导中间智能体（如构建者）的改进；二是为每个智能体设计特定任务奖励，但这需要昂贵的人工标注（如标注关键证据），且容易引发“奖励作弊”（Reward Hacking）。
*   **核心目标**：在无需额外人工标注的情况下，如何从最终的下游任务奖励中精准地为每个异构智能体分配信用（Credit），以实现各司其职的专业化优化。

#### 2. 方法论
论文提出了 **TreeMem** 框架，其核心思想是将线性的多智能体流水线扩展为**树状采样结构**，通过统计学方法估算中间决策的价值。
*   **树状展开（Tree-Structured Rollout）**：在训练阶段，系统不再只生成一条路径，而是进行分支采样。Builder 采样 $G$ 个动作；对于每个 Builder 动作，Summarizer 采样 $J$ 个分支；对于每个组合，Responder 采样 $K$ 个最终回答。
*   **信用分配逻辑**：利用蒙特卡洛平均（Monte Carlo Averaging）将奖励向上回传：
    *   **Responder 信用**：直接使用最终任务奖励。
    *   **Summarizer 信用**：对其下方 $K$ 个响应分支的奖励取平均。
    *   **Builder 信用**：对其下方所有 $J \times K$ 个分支的奖励取平均，并引入**长度惩罚项**（防止其简单复制全文）。
*   **策略优化**：基于 **GRPO**（Group Relative Policy Optimization）算法，利用计算出的特定信用作为优势函数（Advantage），同时更新所有智能体的策略。

#### 6. 主要结论与发现
*   **性能领先**：TreeMem 在所有长程任务基准上均显著优于现有方法，相比最强基准在 PersonaMem 上提升了约 5.5% - 7.5% 的准确率。
*   **专业化效应**：通过树状信用分配，Builder 学会了提取更精炼的证据，Summarizer 学会了更高层次的抽象，而非简单的信息堆砌。
*   **Token 效率**：TreeMem 训练出的模型在生成记忆时更加简洁，显著降低了记忆存储和检索的 Token 开销。

#### 7. 优点
*   **自动化信用分配**：解决了多智能体协作中“功劳归谁”的经典难题，且无需人工定义中间奖励。
*   **端到端一致性**：中间智能体的优化目标与最终任务结果直接挂钩，有效避免了中间任务优化了但最终效果变差的偏差。
*   **部署友好**：树状结构仅存在于训练期，推理期依然是标准的线性流水线。

#### 8. 不足与局限
*   **训练计算成本**：树状采样（$G \times J \times K$）在训练时的计算量和显存需求显著高于普通 RL 方法。
*   **任务类型局限**：目前主要验证了 QA 类任务，对于需要更复杂交互或多步推理的开放式协作任务，其信用分配的有效性尚待进一步探索。
*   **冷启动依赖**：由于依赖最终奖励回传，如果初始策略太差导致所有分支奖励均为零，模型可能难以起步。
