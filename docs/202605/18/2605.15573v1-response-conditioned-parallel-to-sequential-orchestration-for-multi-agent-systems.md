## 摘要
多智能体系统可以通过多个大语言模型（LLM）智能体之间的协作来解决复杂任务。现有的协作框架通常以并行或串行模式运行。在并行模式下，智能体独立响应查询，随后对响应进行聚合。相比之下，串行系统允许智能体通过有向拓扑进行通信，并逐步相互优化。然而，这两种模式都难以在最小化通信和延迟的同时，最大化最终响应的准确性。在这项工作中，我们引入了一种名为 Nexa 的混合范式，这是一种可训练的基于响应条件的策略，弥合了两种模式之间的差距。Nexa 首先进行并行执行阶段，将生成的响应嵌入到共享语义空间中，然后预测一个稀疏的有向无环通信图。如果图为空，系统保持纯并行；如果非空，系统则执行一次串行消息传播。该策略是一个轻量级的 Transformer 模型，且该方法避免了对外部 LLM 评判器或奖励模型的需求，也无需手工设计的测试时拓扑搜索。我们对这一混合执行问题进行了形式化，证明了生成的图在构造上是无环的，且该框架严格包含纯并行执行，并提出了一种基于策略梯度优化的训练程序。结果表明，Nexa 在一种设置下学习到的基于响应条件的策略，在智能体数量、任务或底层智能体发生变化时仍可复用，从而强调了所学通信策略的泛化性。

## Abstract
Multi-agent systems can solve complex tasks through collaboration between multiple Large Language Model agents. Existing collaboration frameworks typically operate in either a parallel or a sequential mode. In the parallel mode, agents respond independently to queries followed by aggregation of responses. In contrast, sequential systems allow agents to communicate via a directed topology and refine one another step by step. However, both modes are inadequate for achieving the desired objectives of minimizing communication and latency while simultaneously maximizing the accuracy of the final response. In this work, we introduce a hybrid paradigm called Nexa, a trainable response-conditioned policy that bridges the gap between the two modes. Nexa begins with a parallel execution stage, embeds the resulting responses into a shared semantic space, and then predicts a sparse directed acyclic communication graph. If the graph is empty, the system remains purely parallel; if it is non-empty, the system performs one sequential message propagation. The policy is a lightweight transformer model, and the method avoids the need for external LLM judges or reward models, as well as hand-crafted test-time topology search. We formalize this hybrid execution problem, show that the resulting graph is acyclic by construction, and that the framework strictly subsumes pure parallel execution, and present a training procedure based on policy-gradient optimization. Results demonstrate that the response-conditioned policy learned by Nexa under one setting can be reused when the number of agents, the task, or the underlying agent changes, thus emphasizing the generalizability of the learned communication policy.

#### 1. 核心问题与整体含义（研究动机和背景）
现有的多智能体系统（MAS）协作模式通常分为两类：**并行模式**（各智能体独立回答后聚合，延迟低但缺乏纠错）和**串行模式**（按拓扑结构逐步改进，准确率高但通信开销和延迟大）。
论文指出，这种二元划分过于僵化。理想的系统应根据智能体生成的**实际响应内容**来动态决定：如果初始回答一致性高，则维持并行；如果存在分歧或互补信息，则启动针对性的串行通信。因此，论文提出了 **NEXA** 框架，旨在通过学习一种“响应条件化”的策略，在最小化通信成本的同时最大化响应准确率。

#### 2. 方法论：核心思想与技术细节
NEXA 的核心是一个五阶段的混合执行流程：
*   **并行草案阶段**：所有 $N$ 个智能体独立生成初始响应 $R^{(0)}$。
*   **语义嵌入**：使用轻量级编码器（如 MiniLM）将响应映射到语义向量空间。
*   **贡献度排序**：计算每个响应向量与平均向量的余弦相似度，作为“贡献得分” $\psi_n$。根据得分确定拓扑顺序 $\pi$，确保信息流向是从高贡献度智能体传向低贡献度智能体，从而在构造上保证**有向无环图（DAG）**的合法性。
*   **图预测策略**：使用一个轻量级的 **Transformer 编码器**处理响应嵌入，预测稀疏通信边。
    *   如果预测结果为**空图**，系统保持纯并行模式，直接聚合。
    *   如果为**非空图**，则执行一轮串行优化，被选中的智能体根据上游节点的响应更新自己的回答。
*   **无评判器聚合**：采用基于加权质心的聚合规则选择最终答案，无需额外的 LLM 作为评判员。
*   **训练算法**：使用 **REINFORCE（策略梯度）** 算法进行优化，并在奖励函数中加入**稀疏性惩罚项**，以抑制过度通信。

#### 6. 主要结论与发现
*   **性能与效率双赢**：NEXA 在保持或提升准确率的同时，比 SelfOrg* 减少了约 **35%** 的 Token 消耗，比 GPTSwarm 减少了超过 **50%**。
*   **强大的迁移能力**：学习到的通信策略表现出“模型无关”和“任务无关”的特性。在小模型（1.5B）上训练的策略可以直接应用于大模型（7B）或新一代模型（Qwen 2.5 到 3.5），且性能损失极小。
*   **稀疏性行为**：随着智能体能力增强，NEXA 倾向于选择更稀疏的通信路径，证明了其能够识别何时“无需多言”。

#### 7. 优点
*   **动态性**：不同于固定拓扑，NEXA 根据“智能体实际说了什么”来决定通信，更具灵活性。
*   **轻量化**：策略网络极小，且无需昂贵的外部 LLM 评判器，推理开销低。
*   **数学完备性**：通过贡献度排序确保了 DAG 的无环性，简化了图生成的约束问题。
*   **高泛化性**：实验证明了策略在不同规模、任务和模型版本间的可复用性。

#### 8. 不足与局限
*   **任务类型限制**：主要集中在有明确答案的推理和编程任务，对于长文本生成、多轮对话或开放式规划等任务的适用性尚待验证。
*   **嵌入模型依赖**：系统的有效性高度依赖于语义嵌入模型（MiniLM）能否准确捕捉响应间的差异。如果嵌入模型无法区分细微的逻辑错误，策略可能会失效。
*   **单轮优化限制**：目前仅支持一轮串行优化，对于极其复杂的、需要多轮迭代纠错的任务，可能需要扩展到多轮通信。
