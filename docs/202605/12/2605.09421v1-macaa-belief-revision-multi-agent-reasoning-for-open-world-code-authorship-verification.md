## 摘要
代码作者身份归属 (CAA) 支持软件取证、抄袭检测和知识产权保护。然而，现有的监督式 CAA 方法受限于训练数据稀缺和封闭世界假设：它们需要来自固定候选作者集的充足标注代码，导致在低数据情况下训练困难，且对于包含未见样本的开放世界测试对或异构代码对的预测不可靠。大语言模型消除了特定任务的训练，但直接提示依赖于昂贵的专家设计提示词，在处理复杂的异构代码对时可能产生幻觉，且很少产生可审计的证据追踪。我们提出了 MACAA，一种基于信念修正的多智能体框架，用于无需训练的代码作者身份验证。MACAA 由一个协调者和四个专家智能体组成，分别分析布局、词法、句法和编程模式证据。协调者通过扩张收集专家信号，通过收缩扣除不可靠证据，并通过修正解决冲突以保持信念一致性，从而用可审计的假设细化取代了直接的 LLM 判断。MACAA 在同语言基准测试中达到了 89.15% 的 F1 值，在混合跨语言对中达到了 80.00%，超越了所有基准模型。

## Abstract
Code authorship attribution (CAA) supports software forensics, plagiarism detection, and intellectual property protection. However, existing supervised CAA approaches suffer from scarce training data and closed-world assumptions: they require sufficient labeled code from fixed candidate-author sets, making training difficult in low-data cases and predictions unreliable for open-world test pairs with unseen samples, or heterogeneous code pairs. Large language models remove task-specific training, but direct prompting depends on costly expert-designed prompts, can hallucinate over complex heterogeneous code pairs, and rarely yields auditable evidence traces. We propose MACAA, a belief-revision-based multi-agent framework for training-free code authorship verification. MACAA comprises a Coordinator and four Expert Agents analyzing layout, lexical, syntactic, and programming-pattern evidence. The Coordinator gathers expert signals for expansion, discounts unreliable evidence through contraction, and resolves conflicts through revision to preserve belief consistency, replacing direct LLM judgment with auditable hypothesis refinement. MACAA achieves 89.15\% F1 on same-language benchmarks and 80.00\% on mixed cross-language pairs, surpassing all baselines.

### 2. 方法论：基于信念修正的多智能体推理
MACAA 的核心思想是引入 **AGM 信念修正理论**（Expansion, Contraction, Revision），将验证过程从“单次判断”转变为“迭代假设细化”。

*   **核心架构**：
    *   **协调者智能体 (Coordinator Agent)**：作为中央控制器，维护初步假设，调度专家，并执行信念修正逻辑。
    *   **四个专家智能体 (Expert Agents)**：分别负责分析 **布局 (Layout)**、**词法 (Lexical)**、**语法 (Syntactic)** 和 **编程模式 (Pattern)**。
*   **关键技术流程**：
    1.  **扩张 (Expansion)**：专家智能体通过 ReAct 模式调用工具提取特征，向共享内存贡献维度特定的证据。
    2.  **收缩 (Contraction)**：协调者识别并削弱不可靠信号。例如，在跨语言场景下，通过“跨语言校准”降低受编程语言语法驱动的信号权重，保留更稳定的编程习惯信号。
    3.  **修正 (Revision)**：通过**结构化辩论 (Debate)** 解决专家间的冲突，并根据校准后的证据更新或保留初步假设。
    4.  **可审计性**：系统记录完整的“证据链”，包括证据的增强、削弱和修正路径，供人工取证审计。

### 6. 主要结论与发现
*   **性能领先**：MACAA 在同语言任务中达到 **89.15% F1**，在混合跨语言任务中达到 **80.00% F1**，显著超过所有监督学习和 LLM 基准。
*   **跨语言鲁棒性**：在语言差异极大的情况下（如 C++ vs Python），MACAA 依然能通过识别高层编程模式保持性能，而其他方法性能大幅下降。
*   **信念修正的价值**：消融实验显示，缺乏“收缩”或“修正”操作会导致模型在面对冲突证据时表现不稳定。

### 7. 优点与亮点
*   **无需训练 (Training-Free)**：直接利用 LLM 的推理能力，解决了取证中样本稀缺的问题。
*   **理论支撑**：将经典的 AGM 信念修正理论与多智能体协作结合，使推理过程具有逻辑严密性。
*   **法庭级可审计性**：生成的证据链不仅给出结论，还解释了为什么某些证据被采纳或被忽略，非常符合软件取证的需求。
*   **跨语言校准**：通过动态调整权重，有效解决了编程语言语法对作者风格识别的干扰。

### 8. 不足与局限
*   **计算成本**：由于涉及多轮迭代、辩论和重检，推理所需的 LLM 调用次数较多，成本和延迟高于单次推理。
*   **模型依赖**：实验仅基于 Qwen3-80B，尚未验证在更小规模模型或其他架构（如 Llama 或 GPT 系列）上的泛化能力。
*   **语言覆盖**：主要针对高资源编程语言，对于低资源语言或经过深度混淆（Obfuscated）的代码，其表现尚待验证。
*   **应用限制**：目前主要针对短代码片段的验证，对于超大规模项目或多人协作代码的拆解能力未做深入探讨。
