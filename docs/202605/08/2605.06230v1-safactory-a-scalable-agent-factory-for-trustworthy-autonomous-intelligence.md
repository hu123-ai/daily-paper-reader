## 摘要
随着大模型从对话助手演变为自主智能体，长程决策、工具使用以及真实环境交互带来的挑战日益增多。现有的智能体基础设施在评估、数据管理和智能体演化方面仍然处于碎片化状态，导致难以系统地发现风险并在持续的闭环中改进模型。在本报告中，我们提出了 Safactory，这是一个面向可信自主智能的可扩展智能体工厂。Safactory 集成了三个紧密耦合的平台：用于轨迹生成的并行仿真平台、用于轨迹存储和经验提取的可信数据平台，以及用于异步强化学习和同策略蒸馏的自主演化平台。据我们所知，Safactory 是首个为下一代可信自主智能提出统一演化流水线的框架。

## Abstract
As large models evolve from conversational assistants into autonomous agents, challenges increasingly arise from long-horizon decision making, tool use, and real environment interaction. Existing agenticinfrastructure remain fragmented across evaluation, data management, and agent evolution, making it difficult to discover risks systematically and improve models in a continuous closed loop. In this report, we present \textbf{Safactory}, a scalable agent factory for trustworthy autonomous intelligence. Safactory integrates three tightly coupled platforms: a \textbf{Parallel Simulation Platform} for trajectory generation, a \textbf{Trustworthy Data Platform} for trajectory storage and experience extraction, and an \textbf{Autonomous Evolution Platform} for asynchronous reinforcement learning and on-policy distillation. As far as we know, Safactory is the first framework to propose a unified evolutionary pipeline for next-generation trustworthy autonomous intelligence.

### 2. 方法论
Safactory 由三个紧密耦合的平台组成：
*   **并行仿真平台 (Parallel Simulation Platform)**：
    *   **核心思想**：通过高并发沙盒环境解决长程任务评估效率低的问题。
    *   **关键技术**：引入**回溯沙盒 (Backtracking Sandbox)** 机制，类似 Git 的版本管理，允许智能体在触发风险或失败时回滚到特定历史节点并探索新的决策分支，避免重复执行前置步骤。
*   **可信数据平台 (Trustworthy Data Platform)**：
    *   **核心思想**：将交互轨迹转化为可检索、可审计的数据资产。
    *   **关键技术**：**DataElf 智能引擎**，支持自然语言驱动的任务编排；**数据价值评估工具**（融合 PPL、IFD、DEITA 等指标的 DataElf Scorer）；**安全审计工具**（集成 23 种检查器，涵盖有害内容、隐私泄露、后门注入等）。
*   **自主演化平台 (Autonomous Evolution Platform)**：
    *   **核心思想**：通过异步强化学习（RL）和在线策略更新实现模型进化。
    *   **关键技术**：**Bridge 模块**解耦采样与训练；支持**同策略蒸馏 (On-policy Distillation, OPD)**，利用教师模型信号修正学生模型的更新方向，增强训练稳定性。
*   **底层支撑**：依托 **DeepLink 计算技术**，实现国产异构芯片（如昇腾、鲲鹏）的大规模推理池化和分布式存储优化。

### 6. 主要结论与发现
*   **能力与安全的权衡**：在 OS 环境中，模型往往在“激进完成任务”和“保守规避风险”间摇摆；而在 Android 环境中，能力强的模型通常安全性也更高。
*   **具身智能瓶颈**：当前模型在具身环境（Embodied Gym）中普遍表现较差，能力与安全性均处于低位，显示出物理交互仍是巨大挑战。
*   **经验提取的价值**：通过轨迹分析工具提取的轻量化经验，使 Kimi-K2.5 在 OS 场景下的安全性从 32.17% 大幅提升至 71.08%。
*   **异步架构优势**：Safactory 的异步架构在相同时间内生成的轨迹数量是原生同步架构的 2.49 倍，显著提升了资源利用率。

### 7. 优点
*   **全生命周期闭环**：打破了评估、数据、训练相互孤立的状态，提出了统一的演化流水线。
*   **回溯机制创新**：回溯沙盒极大地解决了长程交互中“失败即重来”的低效问题，支持分支探索。
*   **国产化适配**：展示了在国产异构算力平台上实现大规模智能体训练与推理的可行性。
*   **工具化程度高**：DataElf 引擎的自然语言驱动特性降低了复杂数据处理的门槛。

### 8. 不足与局限
*   **环境覆盖限制**：虽然涵盖了多种 Gym，但对于涉及复杂人类社会交互、高价值金融/医疗等极端敏感场景的覆盖仍有待加强。
*   **自动奖励设计的难点**：在长程任务中，如何设计完全客观、无偏的自动奖励函数（Reward Function）依然是一个开放性挑战。
*   **泛化性验证**：从特定环境（如 OS）提取的经验能否无缝迁移到其他异构环境，文中缺乏跨领域的迁移实验。
