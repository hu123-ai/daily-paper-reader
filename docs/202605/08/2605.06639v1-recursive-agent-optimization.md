## 摘要
我们提出了递归智能体优化（Recursive Agent Optimization, RAO），这是一种用于训练递归智能体的强化学习方法。递归智能体能够递归地生成自身的新实例，并将子任务委派给这些实例。递归智能体实现了一种推理时扩展算法，该算法自然地允许智能体通过分而治之的方式扩展到更长的上下文，并泛化到更困难的问题。RAO 提供了一种训练模型以充分利用此类递归推理的方法，教会智能体何时以及如何进行委派和通信。我们发现，以这种方式训练的递归智能体具有更好的训练效率，能够扩展到超出模型上下文窗口的任务，泛化到比训练任务困难得多的任务，并且与单智能体系统相比，可以缩短实际运行时间。

## Abstract
We introduce Recursive Agent Optimization (RAO), a reinforcement learning approach for training recursive agents: agents that can spawn and delegate sub-tasks to new instantiations of themselves recursively. Recursive agents implement an inference-time scaling algorithm that naturally allows agents to scale to longer contexts and generalize to more difficult problems via divide-and-conquer. RAO provides a method to train models to best take advantage of such recursive inference, teaching agents when and how to delegate and communicate. We find that recursive agents trained in this way enjoy better training efficiency, can scale to tasks that go beyond the model's context window, generalize to tasks much harder than the ones the agent was trained on, and can enjoy reduced wall-clock time compared to single-agent systems.

#### 2. 方法论
RAO 的核心思想是**将递归执行视为一种可学习的推理原语**，并对递归生成的执行树中的所有节点进行联合优化。

*   **核心动作空间扩展**：在标准的 Python REPL 环境基础上，引入了异步函数 `launch_subagent(goal, ...)`。智能体可以通过编写异步代码同时启动多个子智能体，实现并行处理。
*   **局部节点奖励（Local Node Reward）**：
    公式定义为：$R(X, \tau_X) = \tilde{s}(X, \tau_X) + \lambda \cdot \frac{1}{|C(X)|} \sum_{c \in C(X)} \tilde{s}(c, \tau_c)$
    其中，第一项是当前节点任务的成功信号，第二项是“委派奖励”（Delegation Bonus），即子节点任务的平均成功率。这种设计提供了密集的信用分配（Credit Assignment），引导模型学习有效的委派策略。
*   **策略优化与权重平衡**：
    *   **联合训练**：在递归树的所有深度上训练同一个共享策略 $\pi_\theta$。
    *   **深度频率加权（Depth-level Inverse-frequency Weighting）**：由于递归树深层节点数量远多于根节点，RAO 通过逆频率加权防止优化过程被深层简单任务主导，确保各层级任务平衡。
    *   **留一法基准（Leave-one-out Baseline）**：使用同组根任务的不同 rollout 奖励作为基准来计算优势函数（Advantage），以降低方差。

#### 6. 主要结论与发现
*   **突破上下文限制**：递归智能体能通过将长文本拆分给子智能体，解决远超其训练上下文窗口的任务。
*   **更强的泛化性**：仅在“中等”难度任务上训练的模型，通过递归委派，在“困难”任务上的表现远超单智能体（TextCraft-Synth 成功率从 20% 提升至 88%）。
*   **训练效率提升**：递归结构提供了天然的“课程学习”效应，子任务通常更简单，为模型提供了更易学习的中间信号。
*   **运行时间优化**：在可并行任务中，递归智能体通过并发执行子任务，实际运行时间（Wall-clock time）比单智能体快 2.5 倍。

#### 7. 优点
*   **端到端训练**：不同于以往仅在推理时套用模板的方法，RAO 真正教会了模型“如何委派”。
*   **动态性**：支持动态生成的执行树，而非固定的层级结构，适应性极强。
*   **推理时扩展**：展示了通过增加递归深度（Test-time compute）来解决更难问题的潜力。

#### 8. 不足与局限
*   **顺序任务的开销**：在不可并行的顺序依赖任务（如 DeepDive）中，递归会显著增加 Token 消耗和总耗时（比单智能体慢 18 倍）。
*   **Token 消耗**：虽然在某些长任务中更省 Token，但在需要频繁通信和重复上下文的任务中，递归可能导致 Token 使用量激增。
*   **领域局限**：目前实验主要集中在特定领域（合成、长文档、搜索），尚未验证其作为“通用智能体”在跨领域任务中的迁移能力。
*   **评估成本**：递归 rollouts 的采样成本极高，在大规模 RL 训练中可能面临严重的效率瓶颈。
