## 摘要
高级图表问答既需要对微小视觉元素的精确感知，也需要跨多个子图的多步推理。虽然现有的多模态大语言模型（MLLMs）在理解单张图表方面表现出色，但在跨多个子图的多步推理中往往表现不佳。我们提出了 HierVA，一种用于图表推理的分层视觉智能体框架，它在图文联合空间中迭代地构建和更新工作上下文。高层管理器负责生成计划并维护仅包含关键信息的紧凑上下文，而专门的工作器则执行推理、收集证据并返回结果。特别地，该智能体维护独立的视觉和文本上下文，并使用放大工具来限制视觉上下文。在 CharXiv 推理子集上的实验表明，该方法相比强大的多模态基准模型有持续的提升，消融实验验证了分层架构、限定范围的视觉上下文以及蒸馏后的上下文均贡献了互补的增益。

## Abstract
Advanced chart question answering requires both precise perception of small visual elements and multi-step reasoning across several subplots. While existing MLLMs are strong at understanding single plots, they often struggle with multi-step reasoning across multiple subplots. We propose HierVA, a hierarchical visual agent framework for chart reasoning that iteratively constructs and updates a working context in a joint image--text space. A high-level manager generates plans and maintains a compact context containing only key information, while specialized workers perform reasoning, gather evidence, and return results. In particular, the agent maintains separate visual and textual contexts, using a zoom-in tool to restrict the visual context. Experiments on the CharXiv reasoning subset demonstrate consistent improvements over strong multimodal baselines, and ablation studies verify that hierarchical architecture, scoped visual context, and distilled context contribute complementary gains.

现有的多模态大语言模型（MLLMs）在处理简单图表时表现出色，但在面对**高级图表推理**（如包含多个子图、微小视觉元素、需要多步逻辑跨图表对比的任务）时存在显著缺陷。
*   **核心挑战：** 
    1.  **视觉感知精度不足：** 全局视图下，坐标轴标签、图例等关键细节过于微小，难以识别。
    2.  **上下文单调增长（Monotonic Context Growth）：** 现有的“带图像思考”模式会不断将缩放后的局部图和中间推理过程堆叠在上下文窗口中，导致信息冗余、干扰增加，模型容易“遗忘”早期证据。
*   **研究目标：** 提出一种能够像管理文本推理链一样管理“图文联合上下文”的机制，实现高效、精准的复杂图表推理。

### 2. 方法论：HierVA 框架
HierVA 采用了一种**管理者-工作者（Manager-Worker）**的分层架构，核心思想是“获取、限定范围并蒸馏证据”。

*   **分层架构：**
    *   **管理者（Manager）：** 负责高层规划（两阶段规划：先生成宏观计划，再细化为具体步骤）。它维护一个全局工作上下文，仅保留最终计划和工作者返回的**精炼结果**（如一个数值或一个图像句柄），丢弃中间草稿。
    *   **工作者（Worker）：** 负责执行具体子任务（如“读取子图A的均值”）。每个工作者运行在独立的局部上下文中，只接收任务相关的单张图像（原图或缩放图），其详细推理过程对管理者不可见（封装性）。
*   **关键技术细节：**
    *   **自适应缩放（Adaptive Zoom）：** 管理者可调用缩放工具获取高分辨率局部图。
    *   **即时技能路由（Just-in-Time Skill Routing）：** 维护一个技能库（如 ReadValue, CompareValues），管理者根据任务动态将技能说明注入工作者的系统提示词中，避免上下文膨胀。
    *   **上下文蒸馏与封装：** 通过只保留关键信息，解决了上下文过长导致的信号稀释问题。

*   **精细化控制：** 通过缩放工具和技能路由，实现了对微小视觉元素和复杂逻辑的精准处理。
