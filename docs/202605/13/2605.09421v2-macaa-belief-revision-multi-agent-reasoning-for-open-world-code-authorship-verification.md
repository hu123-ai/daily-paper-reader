## 摘要
代码作者身份归属（CAA）支持软件取证、剽窃检测和知识产权保护。然而，现有的监督式 CAA 方法受限于训练数据稀缺和封闭世界假设：它们需要来自固定候选作者集的充足标注代码，导致在低数据情况下训练困难，且对于包含未见样本的开放世界测试对或异构代码对的预测不可靠。大语言模型消除了特定任务的训练，但直接提示（direct prompting）依赖于昂贵的专家设计提示词，在处理复杂的异构代码对时可能产生幻觉，且很少产生可审计的证据追踪。我们提出了 MACAA，这是一个基于信念修正的多智能体框架，用于无需训练的代码作者身份验证。MACAA 由一个协调者（Coordinator）和四个专家智能体（Expert Agents）组成，分别分析布局、词法、语法和编程模式证据。协调者通过扩张（expansion）收集专家信号，通过收缩（contraction）扣除不可靠证据，并通过修正（revision）解决冲突以保持信念一致性，从而用可审计的假设细化取代了直接的 LLM 判断。MACAA 在同语言基准测试上达到了 89.15% 的 F1 分数，在混合跨语言对上达到了 80.00%，在大多数基准测试上优于所有基线模型，并在所有测试中保持了竞争力。

## Abstract
Code authorship attribution (CAA) supports software forensics, plagiarism detection, and intellectual property protection. However, existing supervised CAA approaches suffer from scarce training data and closed-world assumptions: they require sufficient labeled code from fixed candidate-author sets, making training difficult in low-data cases and predictions unreliable for open-world test pairs with unseen samples, or heterogeneous code pairs. Large language models remove task-specific training, but direct prompting depends on costly expert-designed prompts, can hallucinate over complex heterogeneous code pairs, and rarely yields auditable evidence traces. We propose MACAA, a belief-revision-based multi-agent framework for training-free code authorship verification. MACAA comprises a Coordinator and four Expert Agents analyzing layout, lexical, syntactic, and programming-pattern evidence. The Coordinator gathers expert signals for expansion, discounts unreliable evidence through contraction, and resolves conflicts through revision to preserve belief consistency, replacing direct LLM judgment with auditable hypothesis refinement. MACAA achieves 89.15\% F1 on same-language benchmarks and 80.00\% on mixed cross-language pairs, outperforming all baselines on most benchmarks and remaining competitive on all.

### 2. 方法论：核心思想与关键技术
MACAA 的核心思想是引入 **AGM 信念修正理论（Belief Revision）**，将验证过程视为一个动态的假设演化过程，而非单次分类。
*   **核心架构**：由 1 个**协调者智能体（Coordinator）**和 4 个**专家智能体（Expert Agents）**组成。
*   **专家维度**：
    1.  **布局（Layout）**：缩进、空格、注释位置等格式习惯。
    2.  **词法（Lexical）**：变量命名风格、标识符形态、Token 分布。
    3.  **语法（Syntactic）**：AST 结构、控制流形状、嵌套深度。
    4.  **编程模式（Pattern）**：函数分解逻辑、异常处理习惯、算法偏好（跨语言最稳定）。
*   **信念修正流程（基于 AGM 范式）**：
    *   **扩张（Expansion）**：协调者收集各专家提供的多维度证据，丰富初始假设。
    *   **收缩（Contraction）**：通过“跨语言校准”、“针对性复检”和“结构化辩论”，削弱受编程语言语法干扰或不一致的不可靠证据。
    *   **修正（Revision）**：协调者根据校准后的证据更新初步假设，解决冲突，最终达成一致。
*   **可审计性**：系统记录完整的证据链（Evidence Chain），包括证据的增强、削弱或修改原因，供法证人员审查。

### 6. 主要结论与发现
*   **性能卓越**：MACAA 在同语言任务中 F1 达到 89.15%，在混合跨语言任务中达到 80.00%，显著优于所有基线。
*   **跨语言稳定性**：在语言差异增大时，MACAA 表现出极强的鲁棒性，而其他方法性能大幅下降。
*   **专家权重演化**：实验发现，在同语言验证中，语法和词法最重要；而在跨语言验证中，**编程模式（Pattern）**的权重显著上升（从 0.22 升至 0.48），成为最可靠的指标。
*   **信念修正的价值**：消融实验证明，缺少任何一个修正环节都会导致性能显著下降，尤其是“修正”步骤对处理专家冲突至关重要。

### 7. 优点
*   **无需训练（Training-Free）**：直接适配开放世界，无需为新作者或新语言重新训练模型。
*   **理论支撑扎实**：引入 AGM 信念修正理论，使多智能体协作具有逻辑严密性，而非简单的投票。
*   **高可解释性**：提供完整的证据追踪路径，满足司法取证对“可审计性”的要求。
*   **跨语言能力**：通过模式专家和收缩机制，有效剥离了编程语言本身的干扰信号。

### 8. 不足与局限
*   **计算成本**：由于涉及多轮迭代、辩论和复检，单次验证需要的 LLM 调用次数较多（最多 40 次），推理成本高于直接提示。
*   **模型依赖**：目前仅在 Qwen3-80B 上验证，尚未探讨在更小规模模型或其他架构（如 Llama）上的表现。
*   **语言覆盖**：实验主要集中在高资源编程语言，对于低资源语言或经过深度混淆（Obfuscated）的代码效果尚待验证。
