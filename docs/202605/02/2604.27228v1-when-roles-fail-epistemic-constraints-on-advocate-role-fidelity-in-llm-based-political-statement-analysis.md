## 摘要
民主话语分析系统日益依赖多智能体大语言模型（LLM）流水线，其中不同的评估模型被分配对抗性角色，以生成对政治声明的结构化、多视角评估。一个核心假设是模型将可靠地维持其分配的角色。本文利用 TRUST 流水线对该假设进行了首次系统的实证测试。我们开发了一种认知立场分类器，在不依赖表层词汇的情况下从推理文本中识别辩护者角色，并使用四项指标测量了 60 条政治声明（30 条英语，30 条德语）的角色忠实度：角色漂移指数 (RDI)、预期漂移距离 (EDD)、定向漂移指数 (DDI) 和基于熵的角色稳定性 (ERS)。我们识别出两种失效模式——认知地板效应（事实核查结果产生了一个绝对下限，低于该下限则无法维持合法化角色）和角色-先验冲突（对于事实明确的声明，训练时的知识会覆盖角色指令）——它们是单一机制“认知角色覆盖 (ERO)”的表现。模型选择显著影响角色忠实度：Mistral Large 的表现优于 Claude Sonnet 28 个百分点（67% 对 39%），并且与 Claude 主动切换到对立立场相比，表现出一种定性不同的失效模式——即角色放弃但无极性反转。角色忠实度具有语言鲁棒性。事实核查提供者的选择并非普遍中立：Perplexity 显著降低了 Claude 在德语声明上的角色忠实度（Delta = -15pp, p = 0.007），而对 Mistral 没有影响。这些发现对多智能体 LLM 验证具有直接意义：在没有角色忠实度测量的情况下验证的系统，可能会系统性地歪曲其旨在提供的认知多样性。

## Abstract
Democratic discourse analysis systems increasingly rely on multi-agent LLM pipelines in which distinct evaluator models are assigned adversarial roles to generate structured, multi-perspective assessments of political statements. A core assumption is that models will reliably maintain their assigned roles. This paper provides the first systematic empirical test of that assumption using the TRUST pipeline. We develop an epistemic stance classifier that identifies advocate roles from reasoning text without relying on surface vocabulary, and measure role fidelity across 60 political statements (30 English, 30 German) using four metrics: Role Drift Index (RDI), Expected Drift Distance (EDD), Directional Drift Index (DDI), and Entropy-based Role Stability (ERS). We identify two failure modes - the Epistemic Floor Effect (fact-check results create an absolute lower bound below which the legitimizing role cannot be maintained) and Role-Prior Conflict (training-time knowledge overrides role instructions for factually unambiguous statements) - as manifestations of a single mechanism: Epistemic Role Override (ERO). Model choice significantly affects role fidelity: Mistral Large outperforms Claude Sonnet by 28pp (67% vs. 39%) and exhibits a qualitatively different failure mode - role abandonment without polarity reversal - compared to Claude's active switch to the opposing stance. Role fidelity is language-robust. Fact-check provider choice is not universally neutral: Perplexity significantly reduces Claude's role fidelity on German statements (Delta = -15pp, p = 0.007) while leaving Mistral unaffected. These findings have direct implications for multi-agent LLM validation: a system validated without role fidelity measurement may systematically misrepresent the epistemic diversity it was designed to provide.

*   **研究动机**：现代民主话语分析系统（如 TRUST 流水线）常采用多智能体架构，为不同 LLM 分配对抗性角色（如“批判者”、“中立者”、“辩护者”），通过结构化冲突来提供多视角评估。
*   **核心问题**：系统设计者通常假设模型能可靠地维持分配的角色。然而，如果模型在面对特定事实或政治立场时偏离角色（角色漂移），系统的多视角评估机制就会失效。
*   **研究背景**：作者旨在探索模型在何种条件下会放弃角色，以及这种失效是否具有系统性规律。

### 2. 核心方法论
*   **认知立场分类器（Epistemic Stance Classifier）**：开发了一个基于 Mistral Large 的分类器，不依赖表层词汇，而是通过分析推理文本的“认知取向”来判断其角色：
    *   是否试图使声明“合法化”（辩护者）？
    *   是否试图使声明“去合法化”（批判者）？
    *   是否保持中立（平衡者）？
*   **四项核心度量指标**：
    1.  **角色漂移指数 (RDI)**：衡量从辩护者向批判者漂移的严重程度。
    2.  **预期漂移距离 (EDD)**：预测角色与真实角色之间的平均序数距离。
    3.  **定向漂移指数 (DDI)**：衡量漂移的方向（向批判还是向辩护方向）。
    4.  **基于熵的角色稳定性 (ERS)**：衡量多次运行中角色表现的一致性。
*   **失效机制识别**：提出了**认知角色覆盖 (Epistemic Role Override, ERO)** 统一框架，包含两种模式：
    *   **认知地板效应 (EFE)**：当事实核查结果极度负面时，辩护者角色彻底崩溃。
    *   **角色-先验冲突 (RPC)**：模型训练时的先验知识（认为某事是正确的）覆盖了其扮演批判者的指令。

### 6. 主要结论与发现
*   **认知角色覆盖 (ERO) 是普遍存在的**：当事实与角色指令冲突时，模型倾向于服从事实而非角色。
*   **模型差异显著**：Mistral Large 在角色忠实度上显著优于 Claude Sonnet（67% vs. 39%）。Claude 在失效时倾向于直接反转立场（变成批判者），而 Mistral 更多是放弃角色进入中立状态。
*   **事实核查的影响**：事实核查结果是角色崩溃的主要诱因。有趣的是，证伪（Falsification）的约束力远强于证实（Verification），这体现了模型内置的“波普尔式不对称性”。
*   **语言与提供商**：角色忠实度具有语言鲁棒性，但事实核查提供商的选择会影响特定模型（如 Perplexity 会降低 Claude 的忠实度）。
*   **匿名化局限**：由于模型具有独特的文体指纹（Stylometric Fingerprinting），简单的提示词层面的模型名称匿名化无法完全消除身份偏差。

### 7. 优点
*   **理论创新**：首次系统性地定义并量化了 LLM 在多智能体系统中的“角色忠实度”问题。
*   **度量工具完备**：提出的 RDI、EDD 等指标为未来多智能体系统的验证（Validation）提供了实用工具。
*   **发现深刻**：识别出“认知地板效应”，揭示了模型在处理事实与指令冲突时的深层逻辑。

### 8. 不足与局限
*   **数据集偏差**：英语声明主要集中在美国政治背景，可能限制了在全球其他政治体制下的通用性。
*   **分类器依赖**：虽然使用了 Mistral 作为分类器，但分类器本身的认知偏差（尽管经过测试）仍可能对结果产生微小影响。

*   **应用范围**：主要关注政治话语分析，在其他非政治性、非事实敏感型的多智能体任务中，角色忠实度的表现可能完全不同。
