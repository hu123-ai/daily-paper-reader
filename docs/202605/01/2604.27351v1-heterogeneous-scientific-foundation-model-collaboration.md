## 摘要
智能体大语言模型系统已展现出强大的能力。然而，它们对语言作为通用接口的依赖，从根本上限制了其在许多现实问题中的适用性，特别是在科学领域，这些领域已经开发了特定领域的基座模型来处理自然语言之外的专门任务。在这项工作中，我们介绍了 Eywa，这是一个异构智能体框架，旨在将以语言为中心的系统扩展到更广泛的科学基座模型类别。Eywa 的核心思想是为特定领域的基座模型增加一个基于语言模型的推理接口，使语言模型能够引导非语言数据模态的推理。这种设计允许通常针对专门数据和任务进行优化的预测性基座模型，参与到智能体系统内更高层次的推理和决策过程中。Eywa 可以作为单智能体流水线（EywaAgent）的即插即用替代方案，或者通过用专门的智能体替换传统智能体来集成到现有的多智能体系统中（EywaMAS）。我们进一步研究了一个基于规划的编排框架，其中规划器动态协调传统智能体和 Eywa 智能体，以解决跨异构数据模态的复杂任务（EywaOrchestra）。我们在涵盖物理科学、生命科学和社会科学的多个科学领域对 Eywa 进行了评估。实验结果表明，Eywa 提高了涉及结构化和特定领域数据任务的性能，同时通过与专门基座模型的有效协作，减少了对基于语言推理的依赖。

## Abstract
Agentic large language model systems have demonstrated strong capabilities. However, their reliance on language as the universal interface fundamentally limits their applicability to many real-world problems, especially in scientific domains where domain-specific foundation models have been developed to address specialized tasks beyond natural language. In this work, we introduce Eywa, a heterogeneous agentic framework designed to extend language-centric systems to a broader class of scientific foundation models. The key idea of Eywa is to augment domain-specific foundation models with a language-model-based reasoning interface, enabling language models to guide inference over non-linguistic data modalities. This design allows predictive foundation models, which are typically optimized for specialized data and tasks, to participate in higher-level reasoning and decision-making processes within agentic systems. Eywa can serve as a drop-in replacement for a single-agent pipeline (EywaAgent) or be integrated into existing multi-agent systems by replacing traditional agents with specialized agents (EywaMAS). We further investigate a planning-based orchestration framework in which a planner dynamically coordinates traditional agents and Eywa agents to solve complex tasks across heterogeneous data modalities (EywaOrchestra). We evaluate Eywa across a diverse set of scientific domains spanning physical, life, and social sciences. Experimental results demonstrate that Eywa improves performance on tasks involving structured and domain-specific data, while reducing reliance on language-based reasoning through effective collaboration with specialized foundation models.

*   **核心问题**：LLM 在处理这些结构化科学数据时存在“语言接口瓶颈”，而领域特定的基座模型（FM）虽然预测能力强，但缺乏通用的推理和交互接口。论文探讨了如何让 LLM 智能体与这些异构的、非语言的科学基座模型实现高效协作。
*   **整体含义**：通过建立一种“模态原生”的协作机制，将 LLM 的通用推理能力与科学 FM 的专业预测能力结合，扩展智能体在科学发现中的应用边界。

### 2. 方法论：Eywa 框架
Eywa 框架受电影《阿凡达》启发，提出了三个层次的协作模式：
*   **核心技术：FM-LLM “Tsaheylu” 接口**
    *   **思想**：建立 LLM 与领域 FM 之间的“神经连接”。
    *   **细节**：包含**查询编译器（$\phi$）**（将任务状态翻译为 FM 的结构化调用参数）和**响应适配器（$\psi$）**（将 FM 的专业输出转换回 LLM 可理解的上下文）。通过 **Model Context Protocol (MCP)** 实现标准化交互。
*   **三种实例化模式**：
    1.  **EywaAgent（单智能体增强）**：将 LLM 作为大脑，FM 作为专业技能插件。LLM 动态决定是进行语言推理（skip）还是调用 FM 执行专业计算（invoke）。
    2.  **EywaMAS（多智能体系统）**：在现有的多智能体架构（如讨论、精炼模式）中，用 EywaAgent 替换传统的纯语言智能体，实现跨领域的专家协作。
    3.  **EywaOrchestra（动态编排）**：引入一个“指挥者”（Conductor）规划器，根据输入任务的复杂度和领域，动态选择最优的智能体配置、模型后端和通信拓扑。

### 6. 主要结论与发现
*   **性能提升**：EywaAgent 相比纯 LLM 智能体，在物理、生命和社会科学任务上的效用平均提升约 **7%**。
*   **成本降低**：通过将计算委托给专门的 FM，EywaAgent 减少了约 **30%** 的 Token 消耗，并缩短了约 **10%** 的执行时间。
*   **异构性的价值**：实验证明，**跨模态的异构性**（LLM + 科学 FM）比单纯的**语言模型异构性**（多个不同 LLM 组合）在科学任务中更为关键。
*   **编排优势**：EywaOrchestra 能够以更低的成本实现接近甚至超过专家手动设计的固定多智能体系统的性能。

### 7. 优点
*   **架构创新**：通过 Tsaheylu 接口解决了非语言模型进入智能体系统的工程难题。
*   **效率卓越**：避免了 LLM 在处理长序列数值数据时的“幻觉”和高昂的 Token 成本。
*   **即插即用**：EywaAgent 可以无缝集成到现有的多智能体框架中，具有极高的灵活性。

### 8. 不足与局限
*   **FM 依赖性**：系统的上限受限于所集成的领域基座模型的质量。
*   **领域覆盖**：虽然涵盖了三大科学领域，但对于视觉（如显微图像）、地理空间等更复杂的科学模态尚未完全覆盖。
*   **编排开销**：EywaOrchestra 的规划过程本身会产生一定的延迟和 Token 消耗，对于极简单的任务可能并不划算。
